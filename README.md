# Arcade-Chan-Report
Report channel of Arcade-Chan's issues, features and more.  
See [Issues](https://github.com/MisakaRehana/Arcade-Chan-Report/issues) to report issues, and [Discussions](https://github.com/MisakaRehana/Arcade-Chan-Report/discussions) to discuss about feature requests.  
**This repository is not Arcade-Chan's source code repository, as the codebase is not set to be public.**
